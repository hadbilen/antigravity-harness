## Context

An independent structural and runtime audit (`Fable 5.2`, verified line-by-line against code, live Antigravity documentation, `guard.log`, and live canary subagent probes) surfaced six systemic gaps across safety enforcement, host-contract fidelity, external-project ergonomics, and empirical validation:

1. **Rule 9 Expected-Value Mutation Blind Spot & Silent Circuit Breaker:** Mutating an existing test assertion's expected value (`== 110 -> == 99.0`, `toBe(110) -> toBe(99)`) escaped `PreToolUse`, `stop_gate.py`, and `verify_invariants.py --diff` whenever no manual snapshot was staged; on strike 3, `stop.circuit_breaker_tripped` returned `{}` without firing a throttled operator alert, and non-git workspaces skipped Stop-gate checks silently.
2. **Unverified Antigravity Host Contracts & Toolchain Matrix Breaks:** `pre_invocation.py` gated predictive handoff on `invocationNum == 1` while official `hooks.md` defines `invocationNum` as `0`-indexed; `agents/*.md` omitted `mainAgent: false` and explicit native `tools:` allowlists (exposing `schedule` and `generate_image`); global `GEMINI.md` fell outside IDE/App/CLI unified `~/.gemini/config/rules/` discovery while `48 KB` of harness-internal `MISTAKES.md` installed into every user profile; unconditional `import tomllib` broke Python `3.10` CI; `porter/archive.py` depended on private `zipfile` `fh._left`; `media_qc.py` assumed `ffmpeg >= 5.1`; and `code_map.py` silently returned `0 callers -> Tier 1` on unsupported extensions (`.kt`, `.qml`, `.java`) and JS/TS callback references.
3. **External-Project Overhead, Uncalibrated Heuristics & Readability Debt:** Harness-only rules (Rules 15–17) loaded on every external user project and blocked editing external repos' own `AGENTS.md` / `skills/`; `skills/harness/SKILL.md` compressed 5–10 obligations onto single `> 400`-char lines; skills emitted bare repo-relative paths (`templates/...`, `skills/...`, `guard/hooks/...`) that break outside the harness checkout; `check_ui_slop.py` matched only 5 hardcoded gradient hexes (missing `#667eea -> #764ba2`); `pre_invocation.py` missed natural Turkish prompts (`"Bu projeyi hızlandır"`, `"migration yaz"`, `"Testler neden kırmızı?"`) while false-firing on pasted review blocks and read-only meta-questions; `force_ask` prompts lacked a standardized 3-sentence operator summary; and `guard/agy_hooks.py` gamed its `<= 350`-line cap via a `3,018`-char line.
4. **Unmeasured Real-Project Quality & Surface Growth:** Zero repeatable real-repository A/B measurements existed comparing Harness ON vs. Harness OFF, while the 25-subcommand `agy-guard` CLI, 5 Porter emitters, plugin-packaging questions, and scattered brittle count assertions lacked explicit architectural boundaries.

The decision-driving constraint is **closing every verified safety, host-contract, and Python `3.10` correctness defect while shrinking external-project friction, preserving backward compatibility for existing installed profiles and Porter exports, and anchoring future rule changes to repeatable real-project A/B quality data**.

## Decision

We adopt a four-pillar architectural hardening and governance baseline spanning `W1..W3`:

1. **Default Rule 9 Boundary Enforcement, Fail-Loud Sensors & Python 3.10 Parity (`W1`):**
   - Run `TestBoundaryGuard(workspace_dir=ws).verify(mode="tdd", base_ref="HEAD", authorized_modifications=authorized)` by default inside `guard/hooks/stop_gate.py` for git workspaces (while excluding sibling/pre-existing-dirty test files so pure additive TDD extensions remain allowed) and in `scripts/verify_invariants.py --diff`, closing expected-value test mutations without manual snapshots.
   - Fire throttled desktop alerts (`guard/notifier.py`) and one-line stderr warnings on `stop.circuit_breaker_tripped`, scan `flight_recorder` `touched_files` in non-git workspaces, and exit non-zero with explicit `INCOMPLETE (fallback to text search)` in `scripts/code_map.py` on unsupported extensions and TS/JS callback references.
   - Guard `tomllib` for Python `3.10`, bound `porter/archive.py` spoofed-bzip2 streaming without private `fh._left`, guard `ffmpeg < 5.1` (`-fps_mode` vs. `-vsync`) in `media_qc.py`, anchor turn detection to `transcript.jsonl` `USER_INPUT` across `invocationNum: 0` and `1`, document `AGY_RECORD_HOST_FIXTURES=1` capture/replay in `tests/fixtures/host/README.md`, and gate `tasks.md` recovery on `Campaign ID` / `HANDOFF.md`.
2. **Antigravity Host-Contract Parity, Slim Global Constitution & Scoped Rule 17 (`W2`):**
   - Align all 10 `agents/*.md` profiles to `mainAgent: false`, `subagent: true`, `inheritMcp: false`, canary-verified native read-only `tools:` (`read_file`, plus `search_web` for `research`; verified zero-hang live while stripping `schedule` and `generate_image`), and shared Prompt Defense pointers (injecting `STANDALONE_AGENT_BASELINE` only in Porter exports). Retain the deliberate `agents/research.md` override of Antigravity's built-in `research` agent (explicit `User Constraint` approved in `W2`) so every research delegation obeys the read-only Prompt Defense Baseline and Rule 8 Verification Gap declaration.
   - Install the slimmed global constitution solely to `~/.gemini/config/rules/antigravity-constitution.md` (`trigger: always_on`, including explicit Tier 1 `<20`-line vs. Tier 2 `>=20`-line boundary and Rule 13 `per fix pass` blast cap) while retiring harness `GEMINI.md` and `MISTAKES.md` from global `GOVERNANCE_FILES`; move harness-only maintainer rules (Rule 12 admin addendum and Rules 15–17) into workspace `.agents/rules/harness-maintainer.md` (relying on Antigravity's native rule deduplication documented in `agy-customizations/docs/rules.md` rather than a nonexistent `.agents/rules.json`); and scope Rule 17 model gating strictly to harness checkouts (`.harness/manifest.json` or `guard/agy_hooks.py`), while global `~/.gemini/config` (+ runtime/state) remains unconditionally `deny` under Governance Shield (`GEMINI.md` Rule 12 & Rule 15a).
   - Harden `guard/doctor.py` to check registered hook executable/script paths, `"enabled": false`, dual constitution loading, and native Antigravity `deny` rule recommendations; document `"enabled": false`, official fail-open behavior, and `--dangerously-skip-permissions` in `README.md`.
3. **Decompressed Skills, Installed-Layout Safety, Calibrated Sensors & Operator Ergonomics (`W3`):**
   - Decompress `skills/harness/SKILL.md` into phase-ordered, one-obligation-per-line bullets (`<= 220` chars/line, zero `> 400`-char walls) and move rare swarm orchestration details fully into `skills/harness/references/multi-agent-orchestration.md`.
   - Apply live-verified `disable-model-invocation: true` (confirmed via bundled `native_swarm/SKILL.md` omission from `<skills>`) exclusively to explicit-only skills (`audit`, `retro`, `chisle`, `upstream-auditor`), reclaiming `~1.6 KB` of live per-turn `<skills>` catalog entries (`1,646 B` raw YAML frontmatter / `1,364 B` descriptions) while preserving explicit `/slash` commands and `pre_invocation.py` natural-language hints.
   - Align repo-relative paths across `GEMINI.md`, `agents/*.md`, `skills/**/*.md`, and emitted `pre_invocation.py` hints to installed-layout-safe paths (`~/.gemini/config/...`, `~/.local/share/antigravity-harness/runtime/...`, `agy-guard ...`), add `meta_audit.py` Pass 2 installed-layout path enforcement, and expand `agents/build-error-resolver.md` to TypeScript/JS, Rust/Cargo, Python, Go, Kotlin/Gradle, and QML/CMake.
   - Upgrade `check_ui_slop.py` (`UI-3`) from 5 hardcoded hexes to balanced-paren CSS gradient stop parsing with HSL hue-range math (`235°-335°`, `S >= 30%`, `15% <= L <= 88%`, plus indigo-violet bridge catching `#667eea -> #764ba2` while passing cobalt/slate/teal/warm gradients); calibrate `pre_invocation.py` Turkish routing (`"Bu projeyi hızlandır"`, `"migration yaz"`, `"Testler neden kırmızı?"`) and suppress false hints on pasted audit/review blocks and read-only meta-questions while trimming dead patterns (`vibercoder`, `aksiyomatik tutarlılık`).
   - Standardize 3-sentence plain-language operator headers (*What changes / If approved / If denied*) across `PreToolUse` `force_ask` prompts (including exact test path(s) and diff summary for `## Authorized Test Modifications`), `templates/HANDOFF.template.md`, and `tasks.md`; add parallel-session worktree ledger hygiene in `context-and-artifacts.md`; and reformat `guard/agy_hooks.py` cleanly under a transparent `<= 32,768`-byte (`32 KiB`) and `<= 160`-char/line budget.
4. **Surface Governance Policy & Real-Project A/B Benchmark (`W3`):**
   - **Guard CLI (`6.1`) & Porter (`9`) Surface Freeze:** Retain all `25` existing `agy-guard` subcommands and all `5` Porter emitters (`claude`, `cursor`, `aider`, `universal`, `generic`) for zero-breakage compatibility on `v2.x`, while enforcing a freeze on adding new top-level CLI subcommands or emitters unless backed by measured real-repo demand; track low-use subcommands (such as `provenance` or `request-unlock` / `lock-complete` consolidation) and low-use emitters as candidates for optional `v3.0` consolidation.
   - **Read-Only Antigravity Plugin Packaging (`10`) Deferral:** Keep `install.py` + `~/.gemini/config/` as the authoritative deployment path today and defer native `~/.gemini/config/plugins/antigravity-harness/plugin.json` packaging until Antigravity provides plugin-level parity for non-namespaced slash commands, global `agents/*.md` overrides, `templates/`, and OS-level read-only governance locking.
   - **Brittle Count-Test Minimization (`11.3`):** Retire line-count caps that incentivize minified code (`guard/agy_hooks.py` `<= 350` lines -> byte + line-length cap), prohibit new brittle prose-word or line-count tests in new test modules, and rely on `meta_audit.py` Pass 5 dynamic parity instead of duplicating exact inventory integers across unit test files.
   - **Empirical A/B Benchmark (`13`):** Establish `docs/benchmark-protocol.md` (10 standardized real-project A/B tasks measuring acceptance pass, Rule 9 integrity, Stop-gate strikes, auditor defects, user corrections, wall-clock time, and tokens) and record the initial baseline in `skills/upstream-auditor/references/model-calibration-matrix.md` §4.

## Alternatives Considered

### Alternative 1: Collapse `agy-guard` Subcommands and Drop Non-Claude/Cursor Porter Emitters Immediately (`6.1`, `9`)
- **Pros**: Shrinks CLI parser, documentation surface, and `porter/emitters/` maintenance footprint right away.
- **Cons**: Breaks existing packaged Linux/macOS/Windows users and CI scripts invoking `agy-guard provenance`/`request-unlock`/`boot-check` or `porter.py export --target aider|universal|generic`, violating backward compatibility inside a `v2.x` hardening campaign.
- **Why not**: Rejected as an unrequested breaking change; freezing surface growth on `v2.x` while staging `v3.0` consolidation preserves compatibility without further bloat.

### Alternative 2: Migrate Deployment Immediately to a Native Antigravity Plugin (`~/.gemini/config/plugins/antigravity-harness/plugin.json`, `10`)
- **Pros**: Enables one-click `config.json` enable/disable (`"enabled": false`) and bundles `hooks.json`, `rules/AGENTS.md`, and `skills/` into a single directory.
- **Cons**: Verified against `~/.gemini/antigravity/builtin/skills/agy-customizations/docs/plugins.md`: (a) plugin skills are namespaced, altering established `/harness`, `/audit`, `/chisle`, and `/marathon` invocations; (b) native plugins cannot install `agy-guard`/`agy-porter` PATH binaries or apply OS-level read-only `chmod`/`chattr` locks; and (c) global `agents/*.md` overrides (`research`) and `~/.gemini/config/templates/` do not map 1:1 into plugin directories.
- **Why not**: Rejected on functional loss and breaking UX; documented as a future opt-in track once host plugin specs cover subagents, templates, and non-namespaced triggers.

### Alternative 3: Keep `guard/agy_hooks.py` Under `<= 350` Lines via Single-Line Symbol Packing and Keep Hardcoded Hex Lists (`7.3`, `5.6`)
- **Pros**: Zero existing test modifications required under `GEMINI.md` Rule 9.
- **Cons**: Preserves an unreadable `3,018`-char line (Goodhart gaming of a line-count metric) and misses classic AI purple/indigo gradients like `#667eea -> #764ba2` or `rgb()`/`hsl()` stops.
- **Why not**: Rejected on readability and detection fidelity; replacing the line cap with a transparent `<= 32 KiB` byte budget plus `<= 160`-char line cap (with explicit user-approved Rule 9 test updates) and HSL gradient math enforces both conciseness and maintainability.

## Consequences

### Positive
- Expected-value test mutations are mechanically caught by default in both `stop_gate.py` and `verify_invariants.py --diff` while pure additive TDD tests remain frictionless.
- External user projects pay zero harness-maintainer rule overhead (Rules 15–17 scoped to `.agents/rules/harness-maintainer.md`, `MISTAKES.md` retired from global installs, external `AGENTS.md` / `skills/` unblocked from Rule 17, and `disable-model-invocation: true` trims `~1.6 KB` of live `<skills>` prompt catalog / `1,646 B` raw YAML frontmatter).
- Installed skills and emitted `PreInvocation` hints resolve reliably inside external workspaces and are mechanically audited by `meta_audit.py` Pass 2.
- Operators see concise 3-sentence plain-language context (*What changes / If approved / If denied*) on every `force_ask` prompt, including exact test path(s) and diff summary for `## Authorized Test Modifications`.
- `docs/benchmark-protocol.md` provides a repeatable, blinded real-project A/B measurement methodology to validate future harness changes empirically.

### Negative
- Existing installations upgrading via `python3 install.py` migrate from legacy `~/.gemini/config/GEMINI.md` to `~/.gemini/config/rules/antigravity-constitution.md` (old files are backed up safely, not deleted silently).
- Maintaining `25` `agy-guard` subcommands and `5` Porter emitters until `v3.0` retains existing CLI/emitter maintenance cost until a major-version deprecation window opens.

### Risks
- **Live Antigravity host divergence on `disable-model-invocation: true` in user global `~/.gemini/config/skills/`:** Verified on Antigravity's bundled `native_swarm/SKILL.md` (omitted from `<skills>` while remaining slash-invokable); mitigated by keeping `pre_invocation.py` hints active for natural-language invocations (`"chisle mode"`, `"/audit-upstream"`, `"retrospective"`, `"security audit"`) and verifying after operator `install.py` upgrade.
- **HSL gradient false positives on legitimate purple brand palettes:** Mitigated by requiring saturation `>= 30%`, lightness `15%–88%`, and `235°–335°` hue (passing cobalt blue `#2563eb -> #1d4ed8`, slate, teal, emerald, and warm palettes cleanly). Note: `stop_gate.py` enforces `UI-1`..`UI-5` as blocking findings up to the 3-strike circuit breaker (including `UI-3` at `medium` severity); intentional purple brand palettes can either define explicit brand tokens outside raw purple/indigo linear/radial gradients or rely on operator review/bypass if flagged.
- **Pending real-project A/B benchmark execution:** `docs/benchmark-protocol.md` defines the repeatable harness and schema; empirical Harness ON vs. OFF task runs on external repositories remain to be executed by the operator and recorded in `model-calibration-matrix.md` §4 (declared explicitly under `GEMINI.md` Rule 8).

## Failure Modes & Rollback
- **Installer Constitution Migration Failure (`rules/antigravity-constitution.md`):** Legacy `~/.gemini/config/GEMINI.md` and `MISTAKES.md` are backed up under `~/.local/state/antigravity-harness/backups/` before removal; rollback restores the snapshot via `agy-guard snapshot restore --id <snapshot_id>` (or restores from backup) and re-runs `agy-guard rebaseline`.
- **Hook False-Positive / Emergency Recovery:** If a `PreToolUse` or `Stop` rule blocks urgent work, the human operator opens a lease (`agy-guard request-unlock`), sets `"enabled": false` on the affected `hooks.json` group (flagged explicitly by `agy-guard doctor`), completes recovery, then re-enables and runs `agy-guard lock-complete`.
- **Host Schema Drift (`invocationNum`, `transcriptPath`, `tools:`):** Capture a live sanitized payload via `AGY_RECORD_HOST_FIXTURES=1`, replay against `guard.agy_hooks.dispatch_hook` per `tests/fixtures/host/README.md`, and adjust `guard/hooks/` without weakening existing tests.
