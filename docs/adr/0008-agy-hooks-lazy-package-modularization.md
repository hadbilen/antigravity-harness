# ADR-0008: Event-Scoped Lazy Package Modularization of `guard/agy_hooks.py` into `guard/hooks/`

**Date**: 2026-11-15
**Status**: accepted
**Deciders**: Human Operator, Antigravity Harness Maintainers

## Context

Following `ADR-0004` through `ADR-0007`, `guard/agy_hooks.py` grew to `11,390` lines (`489,824` bytes, `197` functions, `1` class, `195` module constants/regexes, `130` eager `re.compile` calls). Because Antigravity 2.x spawns `python3 guard/agy_hooks.py <event>` as a fresh subprocess on every `PreInvocation`, `PreToolUse`, and `Stop` lifecycle event, initial single-run profiling showed `~359.5 ms` of module import overhead (`749.4–808.7 ms` end-to-end CLI wall time; paired `N=10` idle benchmarks measured `236.10 ms` isolated module load, `943.87 ms` subprocess `import guard.agy_hooks`, and `748.66 ms` `pre-tool-use` CLI) to parse all three lifecycle gates and eagerly compile `52` bilingual `SKILL_HINTS` (`35`) and `ECOSYSTEM_ROUTING_HINTS` (`17`) regular expressions (`67` total `re.compile` calls in the `PreInvocation` slice) that `PreToolUse` never executes. Any refactoring must preserve `100%` observable behavior, `hooks.json` / `install.py` / `guard/approval.py` CLI entrypoints, `scripts/meta_audit.py` Pass 2 AST (`PRE_TOOL_USE_MATCHER_TOOLS`) and Pass 7 (`spec_from_file_location` compiled `re.Pattern` tables) contracts, all `52` externally pinned module attributes (`51` pre-existing external references plus `data_dir`), and all `17` facade-pinned seams (`15` monkeypatched across `tests/` plus `state_dir` and `data_dir`) without modifying existing test assertions (`GEMINI.md` Rule 9).

## Decision

We split `guard/agy_hooks.py` into a thin (`<= 350` lines) lazy-dispatched CLI and PEP 562 compatibility facade backed by an acyclic, event-scoped `guard/hooks/` package:

1. **Event-Scoped Acyclic Package Layout (`guard/hooks/`):**
   - `guard/hooks/__init__.py`: Lightweight package header (`__all__ = ()`) defining only `contextvars.ContextVar` `_ACTIVE_FACADE` (`default=None`) with zero eager submodule imports so importing `guard.hooks.<event>` never pulls sibling lifecycle modules into `sys.modules`.
   - `guard/hooks/common.py`: Strictly shared primitives (`_LazyRegex`, `_facade()`, prompt prose stripping, JSONL tail reader, workspace path discovery, shared flight-recorder ledger readers, `_is_harness_repo_root`, `_is_git_repo_workspace`, and `_extract_normalized_auth_section`). Imports only stdlib, `guard.paths`, and package-relative `from . import _ACTIVE_FACADE`.
   - `guard/hooks/pre_invocation.py`: `SKILL_HINTS` and `ECOSYSTEM_ROUTING_HINTS` (retaining compiled `re.Pattern` objects for `scripts/meta_audit.py` Pass 7), workspace/transcript context routing, and `_detect_workspace_recovery_hint` / `handle_pre_invocation`. Imports only stdlib, `guard.paths`, and package-relative `from .common import ...`.
   - `guard/hooks/pre_tool_use.py`: `WRITE_TOOL_NAMES`, `COMMAND_TOOL_NAMES`, `HIGH_RISK_MCP_TOOL_NAMES`, shell/git/unpinned-package shields, pre-write `flight_recorder` baseline capture, governance/customization Rule 12 & Rule 17 gates, `run_workflow` AST verifier, swarm/subagent/message/schedule gates, `_auth_sections_differ`, `_write_mutates_authorized_test_section`, and `handle_pre_tool_use`. Imports only stdlib, `guard.paths`, and package-relative `from .common import ...` (preserving existing function-local `guard.test_boundary` imports in `_auth_sections_differ`).
   - `guard/hooks/stop_gate.py`: Diff scanners (`inspect_git_diff`, `validate_structured_content`, `_SCANNER_EXEMPT_SUFFIXES` extended with exact root-relative harness-checkout matching on `"guard/hooks/stop_gate.py"` plus split literal regex tokens in `_TEST_RUNNER_SNIFF_RE` so neither `scripts/verify_invariants.py` nor `Stop` self-flags the relocated scanner), `Stop` flight-recorder reconciliation (`quarantine=False` read-only write check), linked-worktree diff collection, strike circuit breaker, and `handle_stop`. Imports only stdlib, `guard.paths`, and package-relative `from .common import ...` (preserving existing function-local `guard.test_boundary` and `guard.audit_log` imports).
2. **Fail-Closed Facade, AST Literal Retention & Dynamic Monkeypatch Forwarding (`guard/agy_hooks.py`):**
   - Retain `PRE_TOOL_USE_MATCHER_TOOLS` as a top-level literal `Tuple[str, ...]` (`PRE_TOOL_USE_MATCHER = "|".join(...)`), fail-closed `main()` / `dispatch_hook()` (including bounded `executionNum < 2` fail-closed `Stop` continuation if `stop_gate` fails to import at bootstrap), import-time `SCRIPT_DIR` / `REPO_ROOT` seeded from `__file__` (dynamically honoring both `REPO_ROOT` and `__file__` overrides in `common._repo_root()`), static `__all__`, and core module globals (`json`, `subprocess`, `tomllib`, `atomic_write_json`, `config_dir`, `configured_config_dir`, `data_dir`, `file_lock`, `state_dir`) directly in `guard/agy_hooks.py`.
   - Register `sys.modules.setdefault("guard.agy_hooks", _main_mod)` on direct CLI `__main__` execution (`sys.argv[0]` resolving to `__file__`) so CLI runs never double-import `guard/agy_hooks.py` while keeping `agy_hooks.py` in `/proc/<pid>/cmdline` for `guard/approval.py` and avoiding global `sys.modules` pollution during in-process `runpy.run_path` execution.
   - Route `main()` through `globals()["dispatch_hook"](event, payload)` and `dispatch_hook()` through `_resolve_handler(handler_name)(payload)` (checking `globals()` before `__getattr__`) so `mock.patch.object(agy_hooks, ...)` overrides win when active and only the single target event submodule loads otherwise.
   - Implement PEP 562 `__getattr__` and `__dir__` over `_SYMBOL_TO_SUBMODULE` without caching resolved submodule attributes into `guard.agy_hooks.__dict__`, ensuring `unittest.mock.patch` / `patch.object` `setattr` and exit `delattr` restore cleanly. Whenever `globals()` is not the registered `sys.modules["guard.agy_hooks"].__dict__` (such as `_meta_audit_agy_hooks` via `importlib.util.spec_from_file_location` in `scripts/meta_audit.py` Pass 7 or in-process `runpy.run_path`) or when `SCRIPT_DIR` differs from cached `sys.modules["guard"].__path__`, `_load_submodule` bootstraps `SCRIPT_DIR / "hooks" / "__init__.py"` as a per-instance synthetic package (`_agy_hooks_pkg_<nonce>`, rolling back `sys.modules` on load failure) and imports `f"{synthetic_pkg}.{submod}"`, while `__getattr__` wraps returned callables and generators to bind that package's `_ACTIVE_FACADE` (`ContextVar`) to `_GlobalsProxy`; `_facade()` checks `_ACTIVE_FACADE.get()` before `sys.modules.get("guard.agy_hooks")`. Extracted submodules dynamically resolve `13` submodule collaborator proxies (`REPO_ROOT`, `__file__`, `atomic_write_json`, `config_dir`, `configured_config_dir`, `data_dir`, `file_lock`, `state_dir`, `json`, `subprocess`, `tomllib`, `_detect_workspace_recovery_hint`, `_batch_update_swarm_workers_ledger`, `handle_pre_tool_use` = `14` attributes across `13` runtime seams, plus `3` `guard/agy_hooks.py` router seams `handle_pre_invocation`, `handle_stop`, `dispatch_hook` = `17` facade-pinned seams) via `_facade_attr()` without swallowing lazy `AttributeError`s.
   - Keep portable `skills/*/scripts/*.py`, `install.py`, and non-hot-path modules untouched (`GEMINI.md` Rule 8 Null-Action Invariant & `porter` single-file portability).

## Alternatives Considered

### Alternative 1: Monolithic Retention with Additional `_LazyRegex` Wrappers Only
- **Pros**: Zero multi-file module boundaries or monkeypatch-forwarding considerations.
- **Cons**: Python still tokenizes, parses, and builds bytecode/function objects for all `11,390` lines on every `PreToolUse` tool call, and `SKILL_HINTS` / `ECOSYSTEM_ROUTING_HINTS` (`52` hint-table regexes; `67` total `re.compile` calls in `pre_invocation.py`) cannot use `_LazyRegex` because `scripts/meta_audit.py` Pass 7 enforces `isinstance(rx, re.Pattern)`.
- **Why not**: Fails the primary hot-path latency and structural maintainability objective; `PreToolUse` still pays `PreInvocation` and `Stop` import costs on every tool call.

### Alternative 2: Custom `types.ModuleType` Subclass Broadcasting `__setattr__` Across Submodules
- **Pros**: Submodules can call imported collaborators as bare module globals instead of `_facade().<sym>`.
- **Cons**: Critical ordering and lifecycle failure mode: patches applied before a submodule is lazily imported (or cleared via `delattr` on `unittest.mock.patch` exit, or mutated on an isolated `_meta_audit_agy_hooks` module loaded via `spec_from_file_location`) desynchronize submodule globals from the active facade.
- **Why not**: Rejected under `mistake-proofing` (Order hazard). Context-aware `_facade()` resolution with uncached PEP 562 `__getattr__` works identically before, during, and after lazy import as well as under isolated `spec_from_file_location` loads.

### Alternative 3: Fine-Grained `8+` Submodule Decomposition (`shell_shield.py`, `workflow_ast.py`, `swarm_gate.py`, etc.)
- **Pros**: Smaller individual files inside `guard/hooks/`.
- **Cons**: `PreToolUse` executes all of those shields on tool calls anyway (zero additional lazy-import savings), exceeds the `marathon` `W1` `<= 8` touched-file blast cap, and multiplies cross-submodule internal imports.
- **Why not**: Rejected under the `harness` §1 Efficiency Ladder (`YAGNI` Brake). Partitioning strictly along the three runtime lifecycle events plus `common.py` achieves maximum event-level lazy isolation with minimal internal coupling.

## Consequences

### Positive
- Invoking `python3 guard/agy_hooks.py pre-tool-use` imports only `guard.hooks.common` and `guard.hooks.pre_tool_use`, completely skipping `SKILL_HINTS`/`ECOSYSTEM_ROUTING_HINTS` (`52` hint-table regexes, `67` total `re.compile` calls) in `pre_invocation.py` and diff scanners in `stop_gate.py` (and symmetrically for `pre-invocation` and `stop`).
- `from guard.agy_hooks import PRE_TOOL_USE_MATCHER` in `install.py` and `guard/cli.py` executes without loading any `guard.hooks.*` submodule.
- Full backward compatibility with all `52` external attribute/import references (`51` pre-existing plus `data_dir`), all `17` facade-pinned seams (`15` monkeypatched across `tests/` plus `state_dir` and `data_dir`), `install.py` (`RUNTIME_ENTRIES = ["guard", ...]`), `package_linux.py`, and `scripts/meta_audit.py` Passes 2 and 7, with `0` edits to existing tests.

### Negative
- Adding a new top-level helper in `guard/hooks/{common,pre_invocation,pre_tool_use,stop_gate}.py` that external callers access via `guard.agy_hooks.<name>` requires registering `<name>` in `_SYMBOL_TO_SUBMODULE` inside `guard/agy_hooks.py`.
- Monkeypatchable collaborators inside `guard/hooks/*` must be accessed via `_facade_attr()` / `_facade()` rather than cached at import time; internal non-seam helpers and constants inside submodules remain direct references by design (`Alternative 2`).

### Risks
- **Unregistered symbol drift or accidental cross-event import**: Mitigated mechanically by `tests/test_agy_hooks_facade_parity.py` (`18` tests), which pins all `52` external attributes, all `17` facade-pinned seams, `ECOSYSTEM_ROUTING_HINTS` subagent target existence, `dir(agy_hooks)` / `__all__` completeness against submodule definitions, fail-closed corrupt ledger handling (`flight_recorder.json`, `environments.json`, `cmd_input_buffers.json`), and subprocess `sys.modules` isolation across `pre-invocation`, `pre-tool-use`, and `stop`.
- **`scripts/meta_audit.py` Pass 2 & Pass 7 split-package drift**: Mitigated by extending `scripts/meta_audit.py` Pass 2 (`pass2_cross_references`) to verify submodule presence and scan `guard/hooks/*.py` alongside `guard/agy_hooks.py` (including split-layout runtime resolution via `hooks_py.parent / "hooks"`), and updating Pass 7 (`pass7_trigger_specificity`) to resolve lazy facade exports directly without 3-argument `getattr` masking `AttributeError`, pinned directly by `tests/test_agy_hooks_facade_parity.py`.
