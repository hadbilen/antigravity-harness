# ADR-0006: Ecosystem Routing Overhaul, Rust 2024 / 1.100.0 Parity, Game-Media-REA Pipeline Integration, and Network/Legacy Boundary Hardening

**Date**: 2026-11-14
**Status**: accepted
**Deciders**: Human Operator, Antigravity Marathon Windows `W1`–`W3` (`a1e746d2-0bd5-4fb4-9712-16321b894652`)

## Context

An empirical diagnostic probe across Antigravity Harness (`25` bilingual English/Turkish prompts and live skill/script audits) identified four cross-cutting architectural gaps:

1. **PreInvocation Ecosystem Routing & Context Blindness (`Paket 1`):** `_collect_invocation_skill_hints` in `guard/agy_hooks.py` filtered candidates using `_VIABLE_HINT_TOKEN_RE` and `pattern.search(scan_text)` *before* checking `_has_explicit_slug_mention`, causing explicit skill and auditor slugs (`deep-grill`, `mistake-proofing`, `test-design`, `build-error-resolver`, `rea_rea`) to be skipped silently when prose lacked generic keyword matches; `"sprite sheet"` misrouted to `game-engineering` instead of `media-studio`; multi-skill prompts were clipped at `MAX_HINTS = 2`; `PreInvocation` ignored workspace domain artifacts (`Cargo.toml` + C/C++, `<canvas>` + `requestAnimationFrame`, `.asar`/`.exe` binaries, audio/sprite assets) and post-user compiler error traces in `transcriptPath`; and `GEMINI.md` lacked an always-on domain routing matrix.
2. **Rust `2024` Edition, `1.100.0` & C++ Migration Drift (`Paket 2`):** `skills/rustify/SKILL.md` and `skills/rustify/references/c-cpp-abi-and-embedded.md` still emitted Rust `2021` FFI syntax (`#[no_mangle] pub unsafe extern "C"`), omitted `1.100.0` stabilizations (`core::mem::DropGuard`, `core::alloc::Allocator`, stabilized never type `!` and pre-2024 fallback caveats, `[registry]` `global-min-publish-age` / `min-publish-age`, `[lints.cargo] unused_dependencies`), lacked a C++ polymorphism/STL/`std::move` matrix and 3-crate workspace split, and left `scripts/code_map.py`'s single-pass `#` directive blanking and linear template masking limits undocumented.
3. **Game, Media, `vibecoder`, and `rea` Disconnection (`Paket 3`):** `skills/game-engineering/SKILL.md` coupled all projects to browser `<canvas>`/`check_ui_slop.py` expectations, lacked explicit input buffering, asset preload gating, save `schemaVersion`, clean-room `reverse-engineer-anything` (`rea_rea`) reference extraction, and brownfield triage (`diagnosing-bugs` vs. `sweetspot` vs. `renew`); `vibecoder` `"mode": "game"` promotions did not mandate `game-engineering` + `media-studio` co-loading; and `skills/media-studio/scripts/media_qc.py` ran two-pass ITU-R BS.1770 `loudnorm` unconditionally, failing with `-inf` on `< 400 ms` game sound effects while lacking Ogg Vorbis (`libvorbis`), zero-crossing loop-seam checking/trimming, nearest-neighbor pixel-art scaling checks, and sprite-atlas geometry/alpha-bleed gates.
4. **Network Controllability & Legacy Port Boundaries (`Paket 4`):** `skills/sweetspot/SKILL.md` (`--net`) did not separate controllable code/wire/OS bottlenecks from uncontrollable external path limits (ISP throughput, geographic speed-of-light `RTT`, upstream API limits), and `skills/renew/SKILL.md` lacked explicit `[HARDWARE/ENV SHIM]` record/replay contracts, Win32/VB6/Flash non-blocking event-loop migration, decimal/date/Turkish `İ/i`/`I/ı` locale traps, and post-parity handoffs (`sweetspot` / `diagnosing-bugs`).

## Decision

1. **Tiered PreInvocation Routing & Bounded Context Signals (`Paket 1` — `guard/agy_hooks.py`, `GEMINI.md`, `skills/harness/SKILL.md`):**
   - Evaluate `_has_explicit_slash_command` and `_has_explicit_slug_mention` / `_has_explicit_route_slug_mention` (covering hyphenated and underscore slugs via `_ROUTE_EXPLICIT_SLUGS` plus single inline backtick commands via `_extract_explicit_inline_command_tokens` while keeping generic regexes scoped to backtick-stripped prose) **before** `_VIABLE_HINT_TOKEN_RE` / regex gating in `_collect_invocation_skill_hints`.
   - Introduce **Tiered Hint Saturation** (`_select_tiered_hints`, targeting `p99 <= 250 ms` hook latency): keep generic regex matches capped at `MAX_HINTS = 2`, unlock up to `MAX_EXPLICIT_HINTS = 4` for explicit slash/slug requests (`remaining_generic = max(0, max_generic - len(explicit))`), keep per-bucket context budgets (`MAX_CONTEXT_SIGNALS = 2` for skills and routes without premature slice starvation), and route `"sprite sheet"` exclusively to `media-studio` alongside expanded bilingual EN/TR `SKILL_HINTS` and `ECOSYSTEM_ROUTING_HINTS`.
   - Add bounded non-symlink context detectors: `_detect_workspace_domain_signals` scanning `depth <= 2`, `<= 200` entries, and `<= 1,000` sorted `scandir` entries per directory while skipping `_is_harness_repo_root` and `_WS_SKIP_DIRS`; and `_iter_jsonl_tail_entries`-backed `_detect_transcript_tool_signals` reading `<= 2 MB` from tail via `O_NOFOLLOW | O_NONBLOCK` + `S_ISREG` strictly after the latest `USER_INPUT` / `USER_EXPLICIT` entry (`> 500`-line threshold, skipping non-exec read/search tools, and resetting on clean exit-0 build passes).
   - Append a compact **Section 6 (`Always-On Domain Skill, Subagent & Server Routing`)** table to `GEMINI.md` (`17,920 <= 20,000` bytes, marking host-only tools with portable fallbacks per Rule 4) and add **Multi-Skill Orchestration Recipes** with an anti-mixing sequencing rule to `skills/harness/SKILL.md`.
2. **Rust `2024` Edition, `1.100.0`, C++ Matrix & `code_map.py` Limits (`Paket 2` — `skills/rustify/`):**
   - Standardize new/migrated crates on **Rust `2024` Edition** and **Rust `1.100.0`+**: `#[unsafe(no_mangle)]` / `#[unsafe(export_name)]` / `#[unsafe(link_section)]`, `unsafe extern "C"` (`pub safe` / `pub unsafe`), `static_mut_refs` (`&raw const` / `&raw mut` / atomics), `unsafe_op_in_unsafe_fn`, `core::mem::DropGuard`, `core::alloc::Allocator`, stabilized `!` (with pre-2024 fallback warning), Cargo `[registry] global-min-publish-age = 259200` (`3` days with explicit zero-day exception) / `min-publish-age` + `incompatible-publish-age = "deny"` + `--locked`, `[lints.cargo] unused_dependencies = "warn"`, 3-crate `*-sys` / `*-core` / `*-ffi` layout (with single-crate `cxx` bridge facade carve-out), a C++ `virtual`/`SFINAE`/STL/`std::move` matrix, and explicit documentation of `scripts/code_map.py` C/C++ preprocessor/template limits requiring `compile_commands.json` / `clangd` / `nm -gC` cross-checks.
3. **Dual-Profile Game Engineering, `vibecoder` + `rea` Bridges, and Opt-In Game QC (`Paket 3` — `skills/game-engineering/`, `skills/vibecoder/`, `skills/media-studio/`):**
   - Split `skills/game-engineering/SKILL.md` into **Profile A (Web / `<canvas>` / WebGL / WebGPU, `16.67 ms` render budget)** and **Profile B (3D & Native Engines, `>= 4.5:1` UI contrast / `>= 14px` readability floor)** (clarifying `check_ui_slop.py` HTML scope and GPU/native resource disposal), add input buffering, asset preload gating, save/replay `schemaVersion` + `<= 3` decode retry / `.corrupt.<timestamp>` quarantine, **Clean-Room Reference Extraction (`rea_rea` Bridge)**, brownfield modification triage, and mandatory `media-studio` external asset co-loading (also wired into `skills/vibecoder/SKILL.md` and `skills/harness/SKILL.md` §6 for `"mode": "game"` promotions).
   - Clarify synthesis (`NumPy`/`SciPy`/`SoundFile`/`FFmpeg lavfi`) vs. QC (`media_qc.py`) separation in `skills/media-studio/SKILL.md` (harmonizing `400 ms` ITU-R BS.1770 gating with `< 0.5 s` `--game-sfx` cutoff and `min(target_tp - 0.6, -1.6)` dBTP inter-sample headroom across lossy codecs) and extend `skills/media-studio/scripts/media_qc.py` with backwards-compatible opt-in flags and rules `GAME-1..GAME-3`: `--game-sfx` / `--peak-db` (linear peak normalization + `astats` Peak `dBFS` silence guard for `< 0.5 s` SFX), `--ogg-codec vorbis|opus` (preserving `libopus` default), `--check-loop` / `--trim-loop` (per-channel rising zero-crossing union snap on audio-only assets with micro-fade fallback and `NaN`/`Inf` finite guards), `--pixel-art` (`-fps_mode passthrough` multi-frame alpha edge check + rotated `_effective_dimensions` + `compare` `4:4:4` upsampled uniform `k x k` block check + `ab-sheet` `flags=neighbor`), and `--sprite-atlas` / `--tile-size WxH` / `--require-pot` / `--check-alpha-bleed` (wall-clock bounded) / `--allow-edge-touch`, plus finite/sign CLI parameter validation, `MAX_GAME_AUDIO_SR` / `MAX_GAME_AUDIO_BYTES`, `-map 0:a:0` / `-map 0:v:0` / `-filter:a` stream-safe commands, and `allow_nan=False` strict JSON serialization.
4. **Network Controllability & Legacy Port Boundaries (`Paket 4` — `skills/sweetspot/SKILL.md`, `skills/renew/SKILL.md`):**
   - Partition `sweetspot --net` into **Controllable Layer** vs. **Uncontrollable External Path Layer**, requiring **Zone 3 Null-Action** reporting when ISP/geographic `RTT`/upstream API limits dominate (`>= 85%` external path share and `< 1%` controllable gain on deterministic fixtures).
   - Add `[HARDWARE/ENV SHIM]` record/replay contracts (`t_k >= t_{k-1}`, `<= 500 ms` peripheral timeouts, `ShimReplayMismatch` drift halts), Win32/VB6/Flash non-blocking event-loop migration (`<= 1` bounded modal continuation queue), decimal/date/Turkish `İ/i`/`I/ı` locale invariants, and explicit post-parity handoffs (`sweetspot` / `diagnosing-bugs`) to `skills/renew/SKILL.md`.

## Alternatives Considered

### Alternative 1: Raise Flat `MAX_HINTS = 4` Globally in `guard/agy_hooks.py`
- **Pros**: One-line constant change (`MAX_HINTS = 4`) without adding `_select_tiered_hints`.
- **Cons**: Breaks existing contract invariant pinned by `tests/test_agy_hooks.py` (`L569-590`, requiring `antislop-contrast` to drop under `MAX_HINTS = 2` when `/audit --meta` competes with generic matches) in violation of `GEMINI.md` Rule 9, and floods prompts with unrequested generic hints.
- **Why not**: Preserving `MAX_HINTS = 2` for generic regex matches while reserving `MAX_EXPLICIT_HINTS = 4` for explicit slash/slug requests and `MAX_CONTEXT_SIGNALS = 2` for workspace/transcript context satisfies both Rule 9 backward compatibility and multi-skill composition (weighted criterion: contract stability and zero prompt noise).

### Alternative 2: Auto-Switch `media_qc.py` `master-audio` Default `.ogg` Codec to `libvorbis` and Auto-Fallback `loudnorm` Silently
- **Pros**: Requires fewer CLI flags when processing short SFX or Unity/Godot `.ogg` assets.
- **Cons**: Silently changes audio codec expectations (`libopus` -> `libvorbis`) for existing Web/streaming callers and hides EBU R128 loudness failures on standard voice/music tracks that unexpectedly fail `loudnorm` gating (`silent-failure-hunter` hazard).
- **Why not**: Opt-in `--game-sfx`, `--peak-db`, `--ogg-codec vorbis`, and `--trim-loop` keep `MEDIA-1..MEDIA-7` and default `loudnorm` / `libopus` behavior intact while giving game pipelines deterministic flags (weighted criterion: backwards compatibility and fail-loud loudness integrity).

### Alternative 3: Unbounded Workspace Traversal in `PreInvocation` Hook
- **Pros**: Detects markers buried arbitrarily deep in large repositories.
- **Cons**: Exceeds the `PreInvocation` hook latency budget on monorepos or follows symlinks outside workspace boundaries.
- **Why not**: Bounding traversal to `depth <= 2`, `<= 200` entries, `<= 1,000` sorted entries per directory, `_WS_SKIP_DIRS`, symlink skipping (`O_NOFOLLOW | O_NONBLOCK` + `S_ISREG`), and `<= 32 KB` / `<= 2 MB` tail streaming guarantees sub-second hook execution and zero symlink/FIFO escapes (weighted criterion: hook latency and boundary safety).

## Consequences

### Positive
- Eliminates explicit slug misses and `"sprite sheet"` misrouting while keeping generic hint noise capped and negative controls at zero false positives (`tests/test_agy_hooks.py` `TestW1RoutingAndContextSignals` and `TestW3HookHardeningAndPrecision`).
- Aligns `rustify`, `game-engineering`, `vibecoder`, `media-studio`, `sweetspot`, and `renew` around shared contracts (`rea_rea`, `media_qc.py` `GAME-1..GAME-3`, post-parity handoffs) under a `17,920`-byte `GEMINI.md` constitution.
- Keeps all existing test assertions unweakened (`0` deleted test lines) while adding `12` W3 regression tests (`613` total AST `def test_*` methods) and synchronizing `.harness/manifest.json` across all 34 skills and 9 subagents.

### Negative
- Increases `guard/agy_hooks.py` `PreInvocation` logic by `~550` lines and `skills/media-studio/scripts/media_qc.py` by `~980` lines (requiring pure-Python PNG/PCM pixel/sample scans bounded by `MAX_GAME_AUDIO_SEC = 300.0`, `MAX_GAME_AUDIO_SR = 384,000`, `MAX_GAME_AUDIO_BYTES = 268,435,456`, and `MAX_GAME_VISUAL_PIXELS = 67,108,864`).
- `GEMINI.md` grows from `15,885` bytes to `17,920` bytes (leaving `2,080` bytes of headroom below the `20,000`-byte operational warning ceiling in `scripts/meta_audit.py` Pass 2).

### Risks & Verification Resolution
- **Risk**: Workspace/transcript auto-signals, pixel/alpha scanning, or `O_NOFOLLOW`/temp-file media paths could introduce edge-case crashes, threshold mismatches, or resource leaks under malformed inputs.
- **Mitigation**: All 7 independent Tier-3 auditors (`meta-auditor`, `consistency-auditor`, `specification-gap-auditor`, `contract-change-auditor`, `test-adequacy-auditor`, `security-boundary-verifier`, `silent-failure-hunter`) ran in `Window 3/3` (`0` CRITICAL findings); every confirmed `HIGH`/`MEDIUM` finding via Mutual Falsification (including `memoryview` integer-block slicing, `apng` `-fps_mode passthrough` infinite-loop decode, `rea_rea` & `rustify` pattern precision, `O_NONBLOCK` FIFO/null-byte file guards, and spec threshold alignment) was fixed and verified with `-W error::ResourceWarning` + `pytest` + Popper's Falsification Gate.
