# Plumbwork Maintainer Rules

Workspace-scoped invariants active only inside the `plumbwork` source repository (excluded from external user projects).

* **Rule 12 (Harness Admin Addendum):** Guard, installer, and Porter administration (`plumb-guard` lock/unlock/rebaseline/policy/notify/startup, `install.py` without `--dry-run`, `porter stage`, governance `chmod`/`chattr`) is human-only; only `plumb-guard request-unlock` is agent-callable.
* **15. Upstream Collisions:** Report `[Upstream Directive Collision]`; stricter rule wins (safety & Rule 9 hold): (a) read-only `~/.gemini/config/` (`sidecars/`/`schedule`), (b) `toolSummary`/`toolAction`, (c) `tailwindcss` CDN in `generative_ui` only, (d) `gh --limit/--jq/--json`, (e) glue-only `run_workflow` (`"inherit"`), (f) no model/Rule 8–17 waiver in `native_swarm` (/grill-me, /learn), (g) `migrate-agent-settings` (`porter inspect` + pinned), (h) `mcp-app-development` CSP, pinned `ext-apps`, secret `ANTIGRAVITY_CSRF_TOKEN`.
* **16. External Rule Ingestion (`porter`):** Inspect external rules/archives read-only (`python3 porter.py inspect`), sanitize sycophancy/test-weakening, require approval on overlaps/violations, and export only from canonical artifacts.
* **17. Self-Audit & Scoped Model Gate:** Global `~/.gemini/config` (and runtime/state directories) remain unconditionally `deny` under Governance Shield (`GEMINI.md` Rule 12 & Rule 15a; human-only via `python3 install.py`). Inside an `plumbwork` checkout (`.harness/manifest.json` or `guard/agy_hooks.py`; never external user projects' own `AGENTS.md`, `GEMINI.md`, `DESIGN.md`, `SKILL.md`, or `.cursor/rules/*.mdc`), editing governance/customization paths (`GEMINI.md`, `AGENTS.md`, `CLAUDE.md`, `DESIGN.md`, `hooks.json`, `mcp_config.json`, `skills.json`, `plugins.json`, `.cursorrules`, `SKILL.md`, `*.mdc`, `.agents/`, `.agent/`, `_agents/`, `_agent/`, `.claude/`, `.cursor/`, `.harness/`, `skills/`, `agents/`, `guard/`, `porter/`, `templates/`, `guard.py`, `porter.py`, `install.py`, `scripts/build_plugins.py`, `scripts/meta_audit.py`, `scripts/verify_invariants.py`) is enforced by `PreToolUse`: approved highest-effort flagships in `skills/upstream-auditor/upstream_state.seed.json` receive `allow` (`(XHigh)` requires `xhigh`, denying `high`/`medium`/`low`; `(High)` allows `high`/`xhigh`, denying `medium`/`low`); Pro-class Orchestrators, unrecognized high-effort flagships, missing metadata, and `MODEL_PLACEHOLDER_*` prompt `force_ask`; Flash/worker tiers, bare known catalog slugs without verified effort, and explicit effort downgrades receive `deny`. Run `python3 scripts/meta_audit.py --all --strict` before completion (`BLOCKED: Harness Meta-Consistency Violation`).
